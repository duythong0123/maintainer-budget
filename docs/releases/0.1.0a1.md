# v0.1.0-alpha.1 — Evidence before policy

Python package version: `0.1.0a1`

Maintainer Budget's first public alpha is intentionally small: it reads merged GitHub PR review history, looks for recurring **human** feedback, and emits evidence-backed repository rule candidates.

## Highlights

- zero-setup GitHub Action: `duythong0123/maintainer-budget@v0`;
- read-only audit; no contributor code execution;
- no API key, database, or server required;
- bot comments ignored by default;
- deterministic clustering with repo-specific identifier anchors;
- batched repository-level comment collection to avoid one API request per PR;
- Markdown, JSON, share-card, and Codex evidence-bundle outputs;
- compact result rendered directly in the GitHub Actions run summary;
- focused real-data regression from two public `openai/codex` review comments about the V2 `camelCase` convention;
- public pilot and scorecard for human ACCEPT / EDIT / REJECT / STALE labels.

## Why alpha?

The project does **not** yet claim production-grade precision. The first public milestone is to collect at least 30 human-labeled candidate clusters across 5–10 public repositories and keep false positives visible.

## Try it

```yaml
name: Maintainer Budget

on:
  workflow_dispatch:

permissions:
  contents: read
  pull-requests: read

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: duythong0123/maintainer-budget@v0
        with:
          max-prs: "100"
```

Run the workflow manually, then inspect the summary directly on the Actions page.

## Pilot
